# UTS_Daspro_SAYA-AKAN-LAWAN-_B

QSC-Quiz Science Computer.

KuisKom adalah program kuis sederhana berbasis Pascal yang menguji pengetahuan dasar tentang komputer melalui lima pertanyaan pilihan ganda.

Fitur Utama dan Logika Program

1. Menu Utama:Menggunakan `case-of` untuk memilih menu mulai kuis, petunjuk, melihat skor, atau keluar.
2. Kuis Pilihan Ganda: Menampilkan lima pertanyaan tentang dasar komputer dengan pilihan jawaban A, B, C, dan D.
3. Pemeriksaan Jawaban: Memeriksa jawaban menggunakan percabangan `if-then-else` dan menghitung jumlah jawaban benar.
4. Perhitungan Skor: Setiap jawaban benar bernilai 20 poin, dengan skor maksimal 100.
5. Komentar Skor: Menampilkan komentar sesuai dengan skor yang diperoleh.
6. Skor Tertinggi: Mencatat skor tertinggi selama program berjalan.
7. Perulangan: Menggunakan `repeat-until` untuk menu utama dan `for-to-do` untuk mengulang pertanyaan kuis.
8. Berhenti Lebih Awal: Menggunakan `break` jika pengguna memasukkan angka `0` saat menjawab kuis.
